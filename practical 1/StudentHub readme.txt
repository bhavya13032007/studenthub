# StudentHub

## Overview

StudentHub is a responsive academic portal designed for students to access
important academic resources from a single platform. The website provides
course information, faculty details, attendance records, campus events,
student authentication, and profile management.

---

## Features

- Responsive user interface
- Centralized student dashboard
- Semester course information
- Faculty details
- Attendance records
- Campus event listings
- Student login system
- Student registration
- Student profile page
- Contact information

---

---

## Modules

### Home
Displays welcome information and quick links.

### About
Provides the mission and objectives of StudentHub.

### Courses
Displays Semester 3 subjects.

### Events
Shows upcoming campus activities.

### Faculty
Lists faculty members and their specialization.

### Attendance
Displays attendance records of students.

### Contact
Provides official contact details.

### Login
Allows students to log into the portal.

### Register
Allows new students to create an account.

### Profile
Displays student information.
